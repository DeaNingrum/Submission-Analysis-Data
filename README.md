# Submission-Analysis-Data

## Deskripsi Project
Dashboard Analisis data yang dibuat menggunakan Phyton dan Streamlit
Dashboard ini digunakan untuk menganalisis data e-commerce, seperti jumlah order, banyak pelanggan dan distribusi data berdasarkan lokasi. 

---

## Fitur Dashboard 
- Visual Data Interaktif
- Analisis Eksploratif
- Tampilan Sederhana

---

## Setup Environment
### Membuat Virtual Environment
```
phyton -m venv venv

```
 Aktivasi Environment : 
 ```
venv\Script\activat
```

Install semua Dependensi :
```
pip install -r requirments.txt
```

---

## Menjalankan Dashboard

Jalankan Perintah : 
```
streamlit run dashboard/dashboard.py
```
